# 识别与保真规范

## 证据表

按 `时间戳 → 页面/状态 → 用户动作 → 画面变化 → 证据文件` 记录整段视频。

| 项目 | 必须记录 |
|---|---|
| 源视频 | 名称、时长、分辨率、方向、声音、剪辑/加速 |
| 画面边界 | 网页视口、宿主外壳、手机系统和播放器 UI 的区别 |
| 页面 | 页面 ID、父页、入口、返回、默认项、空状态 |
| 滚动 | 首屏、容器、完整高度、末尾内容 |
| 文字 | 原文/OCR、置信度、语言、大小写、行数、字体层级 |
| 图片 | 数量、复用关系、比例、位置、裁切、人物一致性 |
| 媒体 | 视频/音乐列表、封面、评论、播放和切换状态 |
| 交互 | 触发、前后状态、动画、是否跨页/跨回合保存 |
| 视觉 | 颜色、间距、栅格、圆角、阴影、透明度、纹理 |

静止帧不能证明点击行为。未播放的媒体只能证明有入口；OCR 不确定不能成为删掉整段的理由。

## 元素清单

同一位置重复的条目定义为“元素族”，如 `gallery-photo`。数量来自参考中的独立槽位；滚动后再次看到同一项不重复计数。缩略图和详情态可分别建行，避免歧义。

采用以下 JSON 结构，路径相对清单所在目录。示例数量仅作格式演示，以本轮参考为准。

```json
{
  "version": 1,
  "pages": [{"id": "gallery", "label": "相册", "evidence": "00:07.800"}],
  "elements": [{
    "id": "gallery-photo",
    "page": "gallery",
    "label": "相册图片",
    "evidence": "00:07.800–00:11.000",
    "expected_count": 2,
    "asset_ids": ["photo-01", "photo-02"],
    "visual": "pending",
    "interaction": "pending",
    "difference": ""
  }]
}
```

`visual` / `interaction` 使用 `passed`、`pending`、`failed`、`not-applicable`；控件不能用不适用跳过交互。`difference` 记录与参考不一致之处。

导出 DOM 在真实对应节点标记 `data-mufy-element="gallery-photo"`。该族两张图就有两个这样的节点。不得为凑数加空节点或隐藏副本。脚本只统计 DOM，不能发现所有遮挡或 CSS 隐藏，必须配合真实截图。

## 素材清单

```json
{
  "version": 1,
  "assets": [{
    "id": "photo-01",
    "kind": "image",
    "source_type": "generated",
    "provenance": "项目原创生成；提示词/生成记录的位置",
    "element_ids": ["gallery-photo"],
    "file": "assets/photo-01.webp",
    "url": "https://实际可用素材主机/photo-01.webp",
    "verification": "pending"
  }]
}
```

`kind` 使用 `image`、`video`、`audio`、`font`；外部代码/样式/媒体嵌入依赖可用 `script`、`stylesheet`、`embed`。`source_type` 使用 `generated`、`user-owned`、`licensed`。本流程的参考替换图片使用 `generated`。来源需指向实际记录/授权依据，不能填“网上找到”。`verification` 使用 `pending` 或 `passed`，仅指素材访问与解码；不能替代正式 MUFY 页测试。示例 URL 必须替换。

完整清单需包含所有素材并和元素双向对应。原生视频 poster 也登记为图片。生成素材依其工具规范获取项目引用，不能为填清单而绕过下载/上传限制。

## 验收顺序

1. 核对页面树、区块和数量，没有少页、少段落、少图、少视频、少评论。
2. 核对比例、位置、层级、密度、图片占屏和文字分布。
3. 核对字体、颜色、装饰、阴影、动画和转场。
4. 重走主路径与各状态：返回、展开、关闭、下一条、暂停。
5. 对参考视口和目标设备各验一次，记录差异与修复。

逐项使用“已核对/有差异/未验证”，不能凭感觉宣布“99% 还原”。原创替换允许画面主体不同；槽位、数量、情绪、功能和布局仍需对应。

## 禁止默认采用的捷径

- 把手机多页结构改成几张卡片或长图。
- 用海报和播放图标代替视频。
- 省略评论、二级菜单、群聊历史、备忘、关系或作者页。
- 不同场景全部使用同一张人物照。
- 用介绍段落代替可点击功能。
- 网站丰富而 MUFY 粘贴版缩水。
- 把未观察到的区域描述成已完整识别。
